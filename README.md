# DimensiTech Static Website

Static, responsive website generated from the supplied Dimensi company profile PDF. No admin console or backend is required.

## Deploy to Vercel
1. Upload this folder to a GitHub/GitLab/Bitbucket repository, or use Vercel's import flow.
2. In Vercel, choose the repository.
3. Framework preset: **Other** (or leave auto-detect).
4. Build command: leave empty.
5. Output directory: `.`
6. Deploy.

You can also drag-and-drop the folder contents in a compatible static deployment workflow.

## Local preview
Run any static server from this directory, for example: `python3 -m http.server 8080`, then open `http://localhost:8080`.

## Source
Visuals and core copy are based on the supplied `Dimensi - Compro170525.pdf`, including the cover, capability visuals, partner visuals, case studies, and contact information.
